# mhkhani.github.io

Public résumé / portfolio page for Mohammad Hossein Khani, served via GitHub Pages at [mhkhani.github.io](https://mhkhani.github.io).

This is a curated, public-facing subset of the full résumé. The complete, continuously-updated version (with tooling to build tailored exports) is maintained in a private repository and is not linked from here by design.

To update this page: edit `index.html` directly, or copy a curated selection from the private résumé's builder tool and adapt it here, then commit and push — GitHub Pages redeploys automatically from the `main` branch.
